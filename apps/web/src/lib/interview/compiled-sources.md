# Compiled Question Sources (Coding + Aptitude)

This file documents the source collections used to compile the expanded Coding and Aptitude question sets.

## Coding Sources

1. LeetCode Top Interview 150
   - https://leetcode.com/studyplan/top-interview-150/
2. GeeksforGeeks Must-Do Coding Questions
   - https://www.geeksforgeeks.org/must-do-coding-questions-for-product-based-companies/
3. Coding Ninjas / Code360 Top Interview Questions
   - https://www.naukri.com/code360/problem-lists/top-interview-questions?source=youtube&campaign=codestudio_toplists

## Aptitude Sources

1. IndiaBIX Aptitude Hub
   - https://www.indiabix.com/aptitude/
2. IndiaBIX Problems on Trains
   - https://www.indiabix.com/aptitude/problems-on-trains/
3. LearnTheta Aptitude Question Collection
   - https://www.learntheta.com/maths-aptitude-questions-and-answers/

## Notes

- Coding entries are compiled as normalized references from these source collections.
- Aptitude entries are generated as interview-style MCQs aligned to common topic patterns from the listed source collections.
- Aptitude entries now include optional visual aids through local SVG assets in `apps/web/public/aptitude-media/`.
- The runtime bank assembly happens in `question-bank.ts` via `compiled-question-sets.ts`.
